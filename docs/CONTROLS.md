# Controls

## Movement and camera
| Key | Action |
|---|---|
| W A S D | Move (steer when riding or rowing) |
| Shift | Sprint; gallop on a horse; row hard in a boat |
| V | Switch between third-person and first-person view |
| F | Free-roam camera (W A S D pans); press F again to return |
| M | Map |

## Combat
| Key | Action |
|---|---|
| Space | Attack |
| 1 · 2 · 3 | Abilities |
| Q | Drink a potion |
| K | Skills window (spend skill points) |

## World and characters
| Key | Action |
|---|---|
| E | Talk to a character; interact; board or leave a coach or boat; tame a horse |
| T | Open the shop or town market (near a stall) |
| L | Trade ledger (prices you have seen) |
| H | Mount or dismount; whistle your horse over |
| R | Rest |
| Z | Sleep |
| ❔ | Help and the one-page training manual |

## Co-op
| Key | Action |
|---|---|
| Enter | Open chat; Tab switches to a private message |
| /w name message | Private (encrypted) message; /r replies |
| G (or middle-click) | Ping a spot on the map for everyone |
| X | Emote bar: wave, cheer, point, dance, bow (keys 1–5) |
| Hold V | Talk, when voice chat is on and push-to-talk mode is selected |

## Story intro
Click, Space or Enter moves to the next panel. Buttons change speed, music and voices, or skip the story.
